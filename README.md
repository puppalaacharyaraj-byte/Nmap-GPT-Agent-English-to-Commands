# 🛡️ NMAP-GPT Agent

An AI-powered Nmap assistant. Ask in plain English, get the exact Nmap command + full explanation of every flag.

## Features
- Firewall evasion techniques
- Stealth scans (SYN, FIN, Xmas, Null, Idle/Zombie)
- Decoy scanning & IP spoofing
- NSE scripts & vulnerability scanning
- OS & service version detection
- Full recon pipelines

## Built With
- React
- Anthropic Claude API

## Usage
Ask anything like:
- "Give me a firewall evasion scan"
- "How do I do an idle zombie scan?"
- "Scan without being detected by IDS"
